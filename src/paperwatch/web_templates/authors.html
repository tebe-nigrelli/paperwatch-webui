Author CSV schema

Headers are trimmed and matched case-insensitively.

ColumnRequiredMeaning
Author NameYesAlso accepts Name or Researcher / author.
InstitutionNoAlso accepts Current lab / organization.
OpenAlex IDNoFor example A123456789. Without it, the author is blog-only.
StarredNoyes, true, 1, on, or starred.
EnabledNoyes/no fetch state.
TagsNoComma-separated tags.
NotesNoMarkdown comments.

Author Name,Institution,OpenAlex ID,Starred,Enabled,Tags,Notes

Blogs CSV schema

Headers are trimmed. The watchlist schema and compact exports are both accepted.

ColumnRequiredMeaning
Researcher / authorYesExact tracked author name.
Primary source URLYesFirst blog/source URL.
Primary applied-ML sourceNoDisplay label.
Primary source type/modeNoExtraction hints.
Primary tags / Blog tagsNoComma-separated source tags.
NotesNoMarkdown source notes in exports.
